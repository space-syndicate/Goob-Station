# Очки уборщика

Отдельная система `JanitorVision`, без зависимости от тепловизора.

- Предмет: `ClothingEyesGlassesJanitor`, доступен в меню спавна и в наполненном шкафу уборщика (`ClosetJanitorFilled`).
- Надеть в слот глаз. Сканер включён по умолчанию, кнопка «Переключить сканер уборщика» включает и выключает его.
- В радиусе 8 метров подсвечивает сквозь стены предметы с тегом `Trash` оранжевыми крестиками, сущности с `PuddleComponent` — голубыми кругами.
- Предметы в руках, сумках и других контейнерах не подсвечиваются. Снятые очки не дают подсветку.
- Радиус и цвета настраиваются полями `range`, `trashColor` и `puddleColor` компонента.
- Подсветка рисуется поверх освещения и FOV. Она использует обычный PVS клиента, без расширения передачи сущностей сервером.

## Проверка

Из корня репозитория:

```powershell
dotnet build Content.IntegrationTests/Content.IntegrationTests.csproj
dotnet test Content.IntegrationTests/Content.IntegrationTests.csproj --no-build --filter FullyQualifiedName~JanitorVisionTest
```

Тесты проверяют надевание, кнопку и сетевое включение/выключение HUD, снятие и удержание в руке, отказ в переключении ненадетых очков, обнаружение мусора и луж за стеной, передачу целей клиенту, удаление убранных целей, дальность, другую карту и содержимое контейнеров.

Для ручной проверки: надеть очки, поставить стену между персонажем и `FoodPacketChipsTrash` / `PuddleVomit`, переключить сканер, затем собрать мусор и убрать лужу. Метки должны пропасть. При снятии очков подсветка отключается.
